# 02：展示頁外殼雙語化與切換

**要建置什麼：** 展示站輸出英文與繁體中文兩個語言版本：英文在輸出根目錄，繁中在 `zh-TW/` 子目錄。頁面外殼的所有使用者可見文字依目前語言顯示，每頁標頭有連到另一個語言同一頁的連結。範例流程圖在這張完成時仍沿用同一份繁中規格，所以英文頁面裡的流程圖文字暫時是中文，這是刻意的中間狀態，由後續票券補齊。

頁面外殼的範圍包含導覽列、各頁標題與描述、標頭按鈕、提示氣泡、事件紀錄訊息、清空按鈕、頁面 `lang` 屬性與 meta 描述。互動頁在瀏覽器內執行的字串也依語言輸出，並且判斷「紀錄是否為空」不再依賴比對某句中文。外殼字串放在以語言為鍵的字典中，兩個語言的字典必須有完全相同的鍵，缺任何一個就無法通過型別檢查。不做瀏覽器語言自動偵測與導向。

縮圖處理：現有縮圖改名為帶 `zh-TW` 後綴的檔名，繁中頁面的社群預覽指向它；英文頁面暫時仍使用目前的主縮圖，內容待票券 06 替換。

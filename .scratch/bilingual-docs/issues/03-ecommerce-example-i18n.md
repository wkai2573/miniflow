# 03：電商範例字典化，建立英文範例的做法

**要建置什麼：** 電商範例改成接受語言參數的工廠：節點、格位、連線、外框、版面與節點類型只存在一份，所有使用者可見文字從依語言區分的字典取得，並寫出英文翻譯。完成後，英文頁面與互動頁的電商圖是英文，繁中頁面維持原樣。這張同時建立字典化的做法與對應測試，供後續票券照辦。

可見文字的範圍包含流程標題、節點標籤與副標、連線標籤、外框標籤、圖例標題與各節點類型名稱、提示文字。字典以語言為鍵，兩個語言的鍵必須完全相同，缺任何一個就無法通過型別檢查。翻譯沿用原本語意，第三方服務名稱照原樣保留，台灣本地的金流名稱以通用英文寫法呈現。

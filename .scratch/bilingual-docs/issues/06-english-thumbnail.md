# 06：英文縮圖

**要建置什麼：** 英文頁面的社群預覽縮圖換成英文標籤的 RAG 流程圖，寬度 800 的 webp，構圖與現有縮圖一致，並沿用主縮圖檔名，英文頁面的 `og:image` 因此顯示英文標籤。繁中頁面繼續使用票券 02 改名後的繁中縮圖。

產生方式是一次性作業，不進建置腳本：用本機瀏覽器對英文 RAG 流程圖截圖，再縮放並轉成 webp。把截圖與轉檔的步驟簡述記錄在開發說明中，之後範例改版時能重做。
